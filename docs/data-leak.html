Handling a client data leak

Use this when client data has been exposed, or might have been. Act quickly and write everything down.

Steps

  1. Contain the incident: close the access, revoke keys, preserve logs. Do not delete evidence.
  2. Inform the client's incident owner and your data protection lead immediately.
  3. Assess what data, how many people and how sensitive. Personal data triggers GDPR duties.
  4. If personal data is affected, the supervisory authority must usually be notified within 72 hours.
  5. Find the root cause and fix it; document the timeline from first signal to fix.
  6. Estimate the cost: response effort, notifications, possible fines, contract penalties.

Common pitfalls

  • Waiting for full certainty before notifying.
  • Fixing the system before evidence is saved.
